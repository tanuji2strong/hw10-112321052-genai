# 03. 任務規劃與推理 (Planning)

當 AI Agent 收到一個簡單的指令（如「今天天氣如何？」）時，它可以很快地給出答案。但如果面對的是一個**複雜、多步驟**的任務呢？例如：「幫我規劃一趟下週去日本京都的三天兩夜自由行，預算三萬台幣，並列出每天的行程表與交通方式」。

這時候，Agent 就需要具備 **任務規劃 (Planning)** 與 **推理** 的能力。它必須像人類一樣，把大問題拆解成小問題，一步步來解決。

## 拆解複雜任務的推理方法

為了讓 Agent 具備更好的推理能力，AI 研究者發展出了幾種不同的提示技巧：

### 1. 思維鏈 (Chain of Thought, CoT)
這是最常見也最基礎的推理方式。簡單來說，就是要求 AI「一步一步來思考 (Let's think step by step)」。

*   **運作方式**：強迫 AI 在給出最終答案前，先把推導過程寫下來。
*   **生活範例**：解決數學題時，不只寫出答案，還要寫出算式。在規劃旅遊時，CoT 會讓 Agent 先思考：「步驟一：確認機票價格；步驟二：確認住宿價格；步驟三：計算剩餘預算來安排景點。」透過寫下步驟，Agent 比較不會犯錯。

### 2. 思維樹 (Tree of Thoughts, ToT)
比思維鏈更進階。有時候解決問題的方法不只一種，如果一條路走到死胡同怎麼辦？思維樹允許 Agent 同時探索多條「不同的思路分支」。

*   **運作方式**：Agent 會想像多個不同的解決方案（分支），評估每一個方案的優劣，然後選擇最好的一條路走。
*   **生活範例**：規劃京都旅行時，Agent 會同時推演兩個方案。
    *   方案 A：住高級飯店，但只能吃平價食物（預算評估：可行，但體驗可能不好）。
    *   方案 B：住平價青旅，但可以吃懷石料理（預算評估：可行，美食體驗佳）。
    Agent 在內部自我評估後，決定採用方案 B 並繼續往下規劃。

## 卡關時的「反思」機制 (Reflection)

人類在做事遇到挫折時會停下來檢討，AI Agent 也具備這樣的能力，這稱為 **反思 (Reflection) 或自我修正**。

在執行任務的過程中，Agent 可能會呼叫到壞掉的 API，或者發現搜尋到的資料不足。具備反思能力的 Agent 不會直接崩潰回傳錯誤給使用者，而是會：

1.  **察覺錯誤**：「我剛剛呼叫的訂房 API 失敗了，回傳了房間已滿的訊息。」
2.  **調整策略**：「既然這間飯店滿了，我應該更改搜尋條件，改找附近的另外三間飯店，重新執行搜尋。」

這種「規劃 $\rightarrow$ 執行 $\rightarrow$ 失敗 $\rightarrow$ 反思 $\rightarrow$ 重新規劃」的能力，是讓 AI Agent 看起來具備高度智慧的關鍵所在。
