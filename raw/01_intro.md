# 01. AI Agents 基本定義與運作原理

## 什麼是 AI Agent？

對於初學者來說，我們通常已經很熟悉像 ChatGPT 這樣的「聊天機器人 (Chatbot)」。當你問它問題時，它會根據訓練資料給你一個文字回答。然而，**AI Agent（人工智慧代理）** 則是比 Chatbot 更進階的形態。

如果說 Chatbot 是一個「很會聊天的百科全書」，那麼 AI Agent 就是一位「具備行動力的數位助理」。

*   **傳統 Chatbot**：只能「說」。你問它「如何規劃一場台北的晚餐？」，它會列出步驟給你。
*   **AI Agent**：能夠「做」。你請它「幫我規劃並訂好今晚台北的晚餐」，它不僅會思考，還會主動去搜尋餐廳、確認你的行事曆、甚至發送 API 請求幫你完成訂位。

## 核心運作迴圈：ReAct 框架

AI Agent 為什麼能夠具備行動力？因為它擁有一個核心的運作機制。目前業界最著名的一種設計框架稱為 **ReAct (Reason + Act)**，也就是「推理」加上「行動」。

一個典型的 AI Agent 運作迴圈包含以下三個主要步驟，並且會不斷循環，直到任務完成：

1.  **感知與觀察 (Observation)**：Agent 會先了解目前的環境與狀態。例如，收到使用者的指令、或是看到上一個步驟執行失敗的錯誤訊息。
2.  **推理與思考 (Reason)**：Agent 內部的「大腦」（也就是大型語言模型 LLM）會開始分析：「我現在需要做什麼？我應該使用哪個工具？下一步的策略是什麼？」
3.  **採取行動 (Act)**：根據思考的結果，Agent 會實際執行動作。例如：呼叫搜尋引擎、執行一段程式碼、或是把結果回報給使用者。

### 生活化範例：請 AI Agent 買咖啡

假設你對 AI Agent 下達指令：「幫我點一杯常喝的咖啡送到公司」。

*   **Reason (思考)**：「使用者想要常喝的咖啡，我需要先查出他常喝什麼。然後我需要知道他的公司地址，最後我需要使用外送 APP 的工具來下單。」
*   **Act (行動 1)**：使用「歷史訂單查詢工具」，查出使用者最常喝的是星巴克的大杯熱拿鐵。
*   **Observation (觀察 1)**：獲得結果「大杯熱拿鐵」。
*   **Reason (思考 2)**：「咖啡確認了，現在我要查詢公司地址。」
*   **Act (行動 2)**：使用「通訊錄工具」查詢公司地址。
*   **Observation (觀察 2)**：獲得結果「台北市信義區 XX 路 XX 號」。
*   **Reason (思考 3)**：「資訊都齊全了，我可以下單了。」
*   **Act (行動 3)**：使用「外送平台 API」送出訂單。

透過這個 **感知 $\rightarrow$ 思考 $\rightarrow$ 行動** 的循環，AI Agent 就能突破單純文字對話的限制，真正替我們在數位世界中完成任務。
