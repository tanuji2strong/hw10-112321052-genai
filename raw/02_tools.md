# 02. 工具使用與 Function Calling

## 為什麼 LLM 需要工具？

AI Agent 的大腦是大型語言模型 (LLM)，雖然它非常聰明、讀過大量的書，但它有兩個致命的先天限制：

1.  **知識截止日 (Knowledge Cutoff)**：LLM 的知識停留在它被訓練的那一天。如果你問它「今天台北的股價指數是多少？」，沒有聯網能力的 LLM 是絕對無法正確回答的。
2.  **無法存取即時或私密資料**：LLM 就像一個被關在房間裡的智者，它無法主動去看看窗外的天氣，也無法登入你的信箱幫你讀信。

為了突破這些限制，我們必須給這個「被關在房間裡的智者」一些工具（例如：一支電話、一台電腦）。在 AI 領域，這就是所謂的 **工具使用 (Tool Use)**。

## Function Calling 的機制

要讓 AI Agent 知道如何使用工具，目前最主流的技術叫做 **Function Calling (函式呼叫)**。

Function Calling 是一個讓 AI 與外部軟體溝通的「橋樑」。它的運作機制如下：

1.  **提供工具清單**：開發者會先告訴 Agent 它有哪些工具可用，並提供工具的「說明書」（例如：這個工具叫 `get_weather`，需要提供 `城市名稱` 才能運作）。
2.  **AI 決定使用工具**：當使用者提出需求時，AI 會判斷自己需不需要工具。如果需要，它不會直接回覆文字，而是輸出一段「指定格式的指令」（通常是 JSON 格式），說：「我要使用 `get_weather` 工具，參數是 `台北`」。
3.  **系統執行工具**：背後的程式碼接收到這個指令後，真的去氣象局抓取資料。
4.  **AI 總結回覆**：系統將抓到的氣象資料丟回給 AI，AI 看懂之後，再用自然語言回覆給使用者：「今天台北的天氣是晴天，氣溫 25 度。」

### 常見的工具範例

*   **查天氣 / 查股價 API**：讓 Agent 獲得即時資訊。
    *   *情境*：「我明天要去東京出差，要帶厚外套嗎？」Agent 會呼叫天氣 API 查詢東京明天的氣溫。
*   **搜尋網頁 (Web Search)**：讓 Agent 可以上網找最新資料。
    *   *情境*：「幫我整理 2024 年奧運的最新賽況。」Agent 會使用 Google 或 Bing 搜尋工具抓取新聞。
*   **執行程式碼 (Code Execution)**：LLM 本身的數學計算能力並不精準，但它可以寫出對的程式碼。
    *   *情境*：「幫我計算這 50 筆發票的總金額，並加上 5% 的稅。」Agent 會寫一段 Python 程式碼，呼叫執行環境算出絕對精準的答案，而不是用猜的。

透過 Function Calling，AI Agent 長出了手和腳，擁有了與真實世界互動的能力。
