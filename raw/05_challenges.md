# 05. 常見誤解與挑戰 (Misconceptions & Challenges)

AI Agents 雖然強大，但它們並不是魔法。對於剛接觸這個領域的初學者來說，很容易對 Agent 抱有錯誤的期待。了解它們的極限與目前的挑戰，能幫助我們更安全、有效地使用它們。

## 初學者常見的兩大誤解

### 1. 以為 AI Agent 具有人類的意識
*   **誤解**：Agent 聽起來很有禮貌，還會自己思考規劃，它是不是有自我意識、甚至有情感？
*   **真相**：完全沒有。AI Agent 的底層仍然是大型語言模型 (LLM)，它本質上是一個超級強大的「文字接龍」機器。它的思考 (Reason) 只是在預測接下來應該輸出什麼文字最合理，並非真正像人類一樣擁有靈魂或意識。

### 2. 以為 Agent 可以 100% 自主運作，不需要人類
*   **誤解**：既然 Agent 會自己規劃任務，那我只要把工作丟給它，就可以去睡覺了。
*   **真相**：目前的技術尚未達到完全可靠的程度。如果把高風險的任務完全交給 Agent，可能會引發災難（例如它可能會因為判斷錯誤，把公司的機密信件群發出去，或是亂花你的信用卡）。

## 目前 AI Agent 面臨的核心挑戰

### 1. 幻覺 (Hallucination)
這是 LLM 最著名的問題。有時候，當 Agent 找不到真實資料，或者推理過程出了差錯，它會**「一本正經地胡說八道」**。
*   *範例*：Agent 可能會捏造一家根本不存在的餐廳，甚至幫你「虛擬訂位」，直到你真的到了現場才發現被 AI 騙了。

### 2. 錯誤累積 (Compounding Errors)
Agent 執行任務通常需要多個步驟。如果它在第一步犯了個小錯，這個錯誤就會像滾雪球一樣，導致後面所有的步驟都錯得離譜。
*   *範例*：你想買一部 2024 年出的手機。Agent 在第一步搜尋時不小心抓到了 2023 年的舊資料（錯誤一）。接著，它拿舊型號去比價（錯誤二），最後幫你下單了錯誤的手機（錯誤三）。

### 3. 需要人類監督：Human-in-the-loop (HITL)
為了解決上述問題，目前業界在設計 Agent 系統時，都會強調 **Human-in-the-loop (人機協作 / 人類在迴圈中)** 的概念。
意思是，Agent 可以幫你做好 90% 的繁瑣工作（搜尋、整理、草擬方案），但在執行**關鍵決策**（如：付款、發送重要郵件、刪除檔案）之前，系統必須暫停，跳出視窗詢問人類：「這是我的計畫，您同意執行嗎？」。

**總結來說**：把 AI Agent 當作一個「能力極強、但偶爾會粗心大意的實習生」。你需要給予明確的指示，並且在關鍵時刻檢查它的工作，這樣才能發揮它最大的價值！
