## Verbatim quotes (copied from the page)

> "Some customers define agents as fully autonomous systems that operate independently over extended periods, using various tools to accomplish complex tasks." [S01]
> "Agents, on the other hand, are systems where LLMs dynamically direct their own processes and tool usage, maintaining control over how they accomplish tasks." [S01]
> "In a LLM-powered autonomous agent system, LLM functions as the agent’s brain, complemented by several key components:" [S03]
> "A system doesn’t need access to external tools to be an agent. However, without external tools, the agent’s capabilities would be limited." [S06]

## Claims (copied from the page)

- 文章指出 agent 有不同的定義：有些人把它當成長時間獨立運作的完全自主系統，也有人用它指稱依照預先定義流程運作的系統。[S01]
- 文章的定義重點是「誰決定流程」：agent 由 LLM 動態決定自己的流程與工具使用。[S01]
- 定義差異：S01 以「誰控制流程」區分 agent 與 workflow，並把兩者都稱為 agentic systems。[S01]
- 定義角度不同：S03 以 LLM 作為「大腦」，再加上規劃、記憶與工具使用三個元件來描述 agent。[S03]
- 兩者都不矛盾，只是切入點不同：S01 強調「誰控制流程」，S03 強調「由哪些元件組成」。
- S06 補充：沒有外部工具也能算是 agent，但能力會受限。[S06]
