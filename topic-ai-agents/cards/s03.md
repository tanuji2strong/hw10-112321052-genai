## Verbatim quotes (copied from the page)

> "In a LLM-powered autonomous agent system, LLM functions as the agent’s brain, complemented by several key components:" [S03]
> "Component One: Planning" [S03]
> "Component Two: Memory" [S03]
> "Component Three: Tool Use" [S03]
> "Subgoal and decomposition: The agent breaks down large tasks into smaller, manageable subgoals, enabling efficient handling of complex tasks." [S03]
> "Reflection and refinement: The agent can do self-criticism and self-reflection over past actions, learn from mistakes and refine them for future steps, thereby improving the quality of final results." [S03]
> "Short-term memory: I would consider all the in-context learning (See Prompt Engineering) as utilizing short-term memory of the model to learn." [S03]
> "It is short and finite, as it is restricted by the finite context window length of Transformer." [S03]
> "Long-term memory: This provides the agent with the capability to retain and recall (infinite) information over extended periods, often by leveraging an external vector store and fast retrieval." [S03]
> "The agent learns to call external APIs for extra information that is missing from the model weights (often hard to change after pre-training), including current information, code execution capability, access to proprietary information sources and more." [S03]
> "LLMs struggle to adjust plans when faced with unexpected errors, making them less robust compared to humans who learn from trial and error." [S03]

## Claims (copied from the page)

- 作者：Lilian Weng
- 網址：https://lilianweng.github.io/posts/2023-06-23-agent/
- 日期：2023-06-23
- 原始檔：[raw/03_weng_llm_powered_autonomous_agents.md](../../raw/03_weng_llm_powered_autonomous_agents.md)
- 文章把 LLM 放在 agent 的核心，並用三個元件補足：規劃（planning）、記憶（memory）與工具使用（tool use）。[S03]
- 規劃包含兩件事：把大任務拆成子目標，以及對過去行動進行自我反省。[S03]
- 短期記憶是 in-context learning，受限於上下文視窗長度。[S03]
- 長期記憶通常是外部向量資料庫，需要時用快速檢索取回。[S03]
- 工具使用：agent 呼叫外部 API 取得模型權重中缺少的資訊。[S03]
- 作者指出規劃的限制：LLM 遇到非預期錯誤時，難以調整計畫。[S03]
