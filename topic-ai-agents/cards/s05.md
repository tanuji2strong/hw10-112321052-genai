## Verbatim quotes (copied from the page)

> "provides a powerful and flexible way for OpenAI models to interface with external systems" [S05]
> "refers to a special kind of response we can get from the model if it examines a prompt, and then determines that in order to follow the instructions in the prompt, it needs to call one of the tools we made available to it." [S05]
> "Tool calling is a multi-step conversation between your application and a model via the OpenAI API." [S05]
> "Receive a tool call from the model" [S05]
> "Execute code on the application side with input from the tool call" [S05]
> "Make a second request to the model with the tool output" [S05]

## Claims (copied from the page)

- 作者 / 機構：OpenAI（API 文件）
- 網址：https://developers.openai.com/api/docs/guides/function-calling
- 日期：文件的目前版本（抓取日期 2026-11-12）
- 原始檔：[raw/05_openai_function_calling.md](../../raw/05_openai_function_calling.md)
- 函式呼叫（function calling，也稱 tool calling）讓 OpenAI 模型能與外部系統互動，並存取訓練資料以外的資料。[S05]
- 「工具呼叫（tool call）」指模型在檢視提示後，判斷需要呼叫某個已提供的工具，於是回傳一個特殊的回應。[S05]
- 工具呼叫是應用程式與模型之間的多步驟對話，流程有五個高階步驟。[S05]
- 流程中，應用程式在自己這一端執行程式碼，再把工具輸出送回模型。[S05]
- [c04 工具使用循環（tool-use loop）](../concepts/c04-tool-use-loop.md)
- 名詞表（glossary）：function calling、tool call
