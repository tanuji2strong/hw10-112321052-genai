概念

什麼是 AI Agent？

  • 完全沒有。 AI Agent 的底層仍然是大型語言模型 (LLM)，它本質上是一個超級強大的「文字接龍」機器。它的思考 (Reason) 只是在預測接下來應 [來源: 05_challenges.md, 「初學者常見的兩大誤解」1]
  • 它沒有意識，只是模式匹配＋工具 [來源: wiki 綜合整理]
  • AI Agent（人工智慧代理） 是比 Chatbot 更進階的形態：如果說 Chatbot 是一個「很會聊天的百科全書」，那麼 AI Agent 就是一位 [來源: 01_intro.md, 「什麼是 AI Agent？」]

先懂 Token：AI 的計費單位

  • Token（詞元） 是 LLM 閱讀與產生文字的基本單位。模型不是以「字」或「詞」處理文字，而是把文字切成 token 再運算。 [補充: 非原始資料]
  • - 英文：一個 token 大約等於 3/4 個單詞。例如 "intelligence" 可能被切成 "in" + [補充: 非原始資料]
  • - 中文：一個中文字通常約等於 1～2 個 token。 [補充: 非原始資料]

概念

Tool Use：讓 AI 動手做事

  • 工具使用 (Tool Use) 是為了突破 LLM 先天限制，給「被關在房間裡的智者」一些工具（例如：一支電話、一台電腦）的做法。 [來源: 02_tools.md, 「為什麼 LLM 需要工具？」]
  • 透過 Function Calling，AI Agent 長出了手和腳，擁有了與真實世界互動的能力。 [來源: 02_tools.md, 結尾段落]
  • 1. 知識截止日 (Knowledge Cutoff)：LLM 的知識停留在它被訓練的那一天。問它「今天台北的股價指數是多少？」，沒有聯網能力的 LLM 絕對無法正確回答。 [來源: 02_tools.md, 「為什麼 LLM 需要工具？」限制 1]

概念

Memory 與 RAG：Agent 的長期記憶

  • 為了提供連貫、個人化的服務，Agent 必須擁有 記憶機制 (Memory)，通常分為「短期記憶」與「長期記憶」。 [來源: 04_memory.md, 開頭段落]
  • 想像你聘請了一位非常聰明的新助理，但他患有嚴重的失憶症，只要你離開辦公室五分鐘，他就會忘記你剛才交代過的所有事情——這樣的助理顯然不合格。AI Agent 也是一樣。 [來源: 04_memory.md, 開頭段落]
