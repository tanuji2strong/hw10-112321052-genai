# Workflow: ingest 一個來源

用於把 raw/ 的一個來源加入 wiki。一次只處理一個來源。規則（引用格式、語言、衝突處理）見 [AGENTS.md](../../AGENTS.md)。

## 步驟

1. 完整讀取 raw/ 中該來源的檔案（不可只讀摘要）。
2. 建立 wiki/sources/sNN.md：
   - 基本資料（作者、網址、日期、原始檔連結）
   - 重點，每個主張附 [Sxx] 與一段逐字引文
   - 這個來源支撐的頁面清單
3. 建立或更新相關的概念、誤解、範例與名詞表頁面。
   - 每個新主張附來源標籤，關鍵主張附引文
   - 若與既有頁面不同，寫入「衝突 / 差異」段落，列出雙方與引文，不替任何一方選邊
   - 若只是用詞不同，記為「用詞差異」
4. 更新 wiki/index.md：來源表狀態改為「已 ingest」，並加入新頁面的連結。
5. 在 wiki/log.md 末尾追加一筆紀錄：日期、來源代號、新增與修改的頁面、衝突記錄、lint 結果。只能追加，不可刪改既有紀錄。
6. 執行 `python3 scripts/wiki_lint.py`。
   - 若有錯誤，修正後重新執行，直到 PASS
   - 引文不符時，改為轉述並刪除該引文，不可修改 raw/ 來配合引文
   - 先執行 lint，再寫入 log 的 lint 結果（不要留下「執行中」之類的佔位文字）
7. 更新 wiki/ingest-summary.md 的來源表與產出頁面清單。

## 完成條件

- lint 為 PASS
- log.md 有本次紀錄，且 lint 結果是實際執行的結果
- index.md 連結了所有新頁面
