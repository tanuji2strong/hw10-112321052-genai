# c02 增強型 LLM（augmented LLM）

## 白話說明

Agent 的「大腦」是 LLM，但單靠 LLM 只能生成文字。加上工具、檢索與記憶之後，它才能查資料、執行動作並保留資訊。這種組合稱為增強型 LLM。

## 來源怎麼說

- S01 把增強型 LLM 當成所有 agent 系統的基本積木。[S01]
> "The basic building block of agentic systems is an LLM enhanced with augmentations such as retrieval, tools, and memory." [S01]
- S03 把 LLM 稱為 agent 的「大腦」，並用三個元件補足它：規劃、記憶與工具使用。[S03]
> "In a LLM-powered autonomous agent system, LLM functions as the agent’s brain, complemented by several key components:" [S03]

## 衝突 / 差異

- 無衝突。兩者都把 LLM 放在核心位置，S01 用「增強型」來描述，S03 用「大腦」與三個元件來描述。
