# m03 誤解：agent 越複雜越好

## 常見誤解

初學者常以為做出越多步驟、越多 agent 的系統就越強。

## 來源怎麼說

- S01 建議先找最簡單的解法，只在需要時才增加複雜度，甚至可能不需要 agent。[S01]
> "When building applications with LLMs, we recommend finding the simplest solution possible, and only increasing complexity when needed." [S01]
- S01 也指出，成功不在於做出最精密的系統，而在於做出適合需求的系統。[S01]
> "Success in the LLM space isn't about building the most sophisticated system. It's about building the right system for your needs." [S01]

## 正確理解

先從簡單的 prompt 或單次 LLM 呼叫開始，只有在簡單方法不夠時，才加入多步驟的 agent 流程。[S01]
