# m01 誤解：agent 是完全自主、不需要人參與的

## 常見誤解

初學者常以為 agent 一旦啟動，就會獨立完成所有工作，不需要人介入。

## 來源怎麼說

- 有些人把 agent 定義為長時間獨立運作的完全自主系統，但 S01 指出 agent 常從人的指令或討論開始。[S01]
> "Agents begin their work with either a command from, or interactive discussion with, the human user." [S01]
- S06 指出，人可以在規劃、驗證與執行的任何階段參與，以降低風險。[S06]
> "So far, we’ve assumed that the agent automates all three stages: generating plans, validating plans, and executing plans. In reality, humans can be involved at any stage to aid with the process and mitigate risks." [S06]

## 正確理解

Agent 可以在很多步驟上自己工作，但實際系統通常仍需要人在起點、檢查點或高風險動作上參與。[S01][S06]
